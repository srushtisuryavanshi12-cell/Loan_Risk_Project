# 🏦 Loan Default Early Warning & Portfolio Risk Analytics System

An end-to-end Machine Learning Early Warning System (EWS) that computes default probabilities for loan applications and triggers real-time underwriting risk tiers.

## 📌 Features
- **Data Preprocessing Pipeline:** Cleans and processes ~1.3 million historical LendingClub loan records into binary risk targets.
- **Predictive Model:** Scaled Logistic Regression model outputting calibrated probability scores.
- **Interactive Dashboard:** Built with Streamlit to enable real-time risk classification and decision triggers.

## 🛠️ Tech Stack
- **Languages & Frameworks:** Python, Streamlit
- **Data & ML:** Pandas, NumPy, Scikit-learn, Joblib
- **IDE:** Visual Studio Code
